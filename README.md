# Books App

Android application for browsing and searching books using the Google Books API.
Built independently to practice MVVM architecture and Android Architecture Components.

## Features

- Search books by title, author, or keyword via the Google Books API
- Browse book details: cover image, description, author, publication info

 
## Tech Stack

Kotlin · Android SDK · MVVM · [Retrofit/Volley] · [LiveData/StateFlow] · Google Books API

## Setup

1. Clone the repo
2. Open in Android Studio
3. Run on an emulator or physical device (min SDK [X])
